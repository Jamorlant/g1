## 1. 架构设计

```
┌─────────────────────────────────────────────────────────┐

├─────────────────────────────────────────────────────────┤

│  │  游戏状态   │  │  渲染引擎   │  │   音效系统      │  │
│  │  管理器     │  │  (CSS 3D)   │  │   (Web Audio)   │  │
│  └─────────────┘  └─────────────┘  └─────────────────┘  │
├─────────────────────────────────────────────────────────┤

│  │                   游戏逻辑层                      │    │
```

## 2. 技术栈

| 类别 | 技术 | 说明 |
|------|------|------|
| 核心 | HTML5 + CSS3 + JavaScript | 单HTML文件，无构建工具 |
| 3D渲染 | CSS 3D Transforms + Perspective | 实现螺旋棋盘立体效果 |
| 动画 | CSS Keyframes + Transitions | 棋子移动、特效光效 |
| 图标 | Unicode Emoji | 星星⚡翅膀宝箱等 |

## 4. 核心游戏逻辑

### 4.1 回合流程
```
1. 检查当前玩家是否被冰封 → 是则跳过
2. 玩家选择石头/剪刀/布
3. 双方同时亮出选择
4. 判断胜负 → 移动棋子
5. 触发特殊格子效果
6. 检查胜利条件
7. 切换玩家
```

### 4.2 胜负判定
```javascript
// 胜利条件：4枚棋子全部到达终点（第60格）
function checkWin(player) {
  return player.pieces.every(pos => pos >= 60)
}
```

### 4.3 技能释放时机
- 可在任何自己回合的任意时刻点击技能按钮
- 释放后立即生效，不消耗回合
- 技能释放后能量清零

## 6. CSS 3D 螺旋棋盘实现

```css
.board-container {
  perspective: 1000px;
  transform-style: preserve-3d;
}

.layer {
  transform: rotateX(var(--rotation)) translateZ(var(--height));
  /* 每层不同的旋转角度和Z轴位移实现螺旋上升效果 */
}
```

## 7. 性能优化

- 使用 CSS transform 代替 top/left 动画（GPU加速）
- 避免在动画中触发重排（reflow）
- 合理使用 will-change 提示浏览器
