# 创意飞行棋 - 产品需求文档

## 1. 产品概述

**「创意飞行棋」** 是一款创新型双人实时对抗飞行棋游戏，将传统掷骰子机制替换为「石头剪刀布」博弈系统，融入英雄技能与能量爆发机制，配合3D螺旋上升棋盘，为玩家带来策略与运气并存的对战体验。

### 核心亮点
- **剪刀石头布代替骰子**：石头=0步+蓄能，剪刀=2步，布=5步，每一次出拳都是策略抉择
- **英雄技能系统**：选择你的英雄，每位英雄拥有独特的终极技能
- **3D螺旋棋盘**：螺旋上升的立体棋盘，越高层奖励/挑战越高
- **能量爆发**：对局中积攒能量，满能量时释放英雄终极技能扭转战局

## 2. 核心功能

### 2.1 英雄选择系统

| 英雄 | 称号 | 终极技能 | 技能效果 |
|------|------|----------|----------|
| 烈焰 | 火焰使者 | 「烈焰冲击」 | 下一次移动强制前进8步 |
| 寒霜 | 冰霜女王 | 「冰封领域」 | 对手暂停1回合 |
| 疾风 | 风之精灵 | 「瞬影步」 | 立即移动3步 |
| 大地 | 岩石巨人 | 「地动山摇」 | 将对手击退5步 |

### 2.2 石头剪刀布机制

| 出拳 | 胜利效果 | 失败效果 |
|------|----------|----------|
| 石头 | 前进0步 + 蓄能+15 | 后退2步 |
| 剪刀 | 前进2步 | 后退3步 |
| 布 | 前进5步 | 后退1步 |

- **能量蓄积**：每次出石头（无论胜负）获得15点能量
- **满能量**：100点能量时自动解锁终极技能按钮
- **技能释放**：消耗全部能量释放技能，可在对局任意时刻使用

### 2.3 3D螺旋棋盘设计

- **结构**：共5层螺旋上升棋盘
- **第1层（起点）**：安全区，无特殊效果
- **第2-4层**：分为以下特殊格子类型
  - ⭐ 星星格：获得额外前进加成（+2步）
  - ⚡ 闪电格：强制与对手交换位置
  - 翅膀格：直接跃飞3步
  - 宝箱格：随机获得能量（+10~+30）
- **第5层（终点）**：首先将全部4枚棋子移入终点区域的玩家获胜

### 2.4 游戏流程

```
开始界面 → 英雄选择（双方各选） → 石头剪刀布对局 → 移动棋子 → 检查特殊格子效果
     ↑                                                      ↓
     ←←←←←←←←←←←←←←←←←←←←←←←←←←←←←←←←←←←←←←←←←←←←←←←←←←←←
                    ↓
              检查胜利条件（4枚棋子全部到达终点）
                    ↓
              胜利结算界面
```

## 3. 用户界面设计

### 3.1 设计风格
- **主题**：赛博朋克 + 奇幻魔法融合风格
- **色调**：深蓝底色（#0a0e27）+ 霓虹渐变（青/紫/粉）+ 金属质感高光
- **字体**：Orbitron（标题）+ Exo 2（正文）
- **特效**：粒子光效、霓虹辉光、3D透视

### 3.2 页面结构

| 页面 | 模块 | 描述 |
|------|------|------|
| **开始页** | 标题动画 | 3D浮动标题 + 粒子背景 |
|  | 开始按钮 | 霓虹发光按钮 |
|  | 规则按钮 | 弹出规则说明 |
| **英雄选择页** | 英雄展示 | 4个英雄卡片，悬停显示详情 |
|  | 确认按钮 | 选定英雄后点击确认 |
| **游戏页** | 棋盘区 | 3D螺旋棋盘居中显示 |
|  | 玩家状态栏 | 显示双方棋子位置、生命值、能量条 |
|  | 控制区 | 石头/剪刀/布 三个按钮 |
|  | 技能区 | 终极技能按钮（满能量时亮起） |
|  | 消息区 | 显示对局结果、特殊格子效果 |
| **结算页** | 胜负展示 | 胜者庆祝动画 / 败者安慰动画 |
|  | 重新开始按钮 | 返回开始页 |

### 3.3 响应式设计
- **桌面端优先**：1200px+ 完整体验
- **平板适配**：768px-1199px 棋盘缩放，按钮保持可点击
- **手机端**：最小支持 375px，竖屏布局

## 4. 技术实现

### 4.1 技术栈
- **渲染**：纯HTML5 + CSS3 + JavaScript（单文件）
- **3D效果**：CSS 3D transforms + 透视
- **动画**：CSS Animations + Keyframes
- **无外部依赖**：所有代码自包含

### 4.2 核心数据结构

```javascript
// 玩家状态
player = {
  name: "玩家1/玩家2",
  hero: "烈焰|寒霜|疾风|大地",
  energy: 0,        // 0-100
  pieces: [0,0,0,0], // 4枚棋子当前位置（格子索引）
  isStunned: false  // 是否被冰封暂停
}

// 棋盘格子
cell = {
  index: 0-59,      // 格子编号
  layer: 1-5,       // 所在层级
  type: "normal|star|lightning|wing|treasure", // 格子类型
  effect: null      // 特殊效果函数
}
```
